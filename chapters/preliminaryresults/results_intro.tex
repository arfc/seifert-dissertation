The preliminary results use the 0D scaled model, discussed in Section \ref{sec:data-model}, to generate improved \gls{DNP} group parameters.
The results verify the \gls{DNP} group parameters using stationary thermal fission of $^{235}$U for which extensive experimental data exist.
These preliminary results investigate individual \glspl{DNP}, \gls{DNP} group parameter sensitivities, and \gls{DNP} group parameter verification.
