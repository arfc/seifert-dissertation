This work aims to generate more accurate \gls{DNP} group parameters for \glspl{MSR} and implement those parameters for safety, security, and safeguards design purposes.
These \gls{DNP} group parameters in \glspl{MSR} differ because fuel circulates and undergoes online chemical reprocessing.
These effects can be captured in spatially resolved \gls{MSR} fuel depletion simulations.
The existing methodology for \gls{DNP} group parameter generation does not account for the physical phenomena present in \gls{MSR} fuel depletion \cite{keepin1957delayed, tuttle1975delayed, manero1972status, benedetti1982delayed, waldo1981delayed, brady1988evaluation, hughes1948delayed, loaiza1998measurements, loaiza2000dominant, pfeiffer2002status, d2002review, pfeiffer2002status, rudstam2002delayed, wilson2002delayed, brady1989delayed, leconte2020new}.
More accurate \gls{DNP} group parameters are generated by accounting for these physical phenomena, which is particularly important for safety, security, and safeguards related concerns.
