This work aims to generate more accurate \gls{DNP} group parameters for \glspl{MSR} and implement those parameters in safeguards and safety-related transient scenarios.
A background is necessary to properly motivate these aspects of this work.
Nuclear safeguards and safety-related reactor transients are the primary motivators behind this work, so they are discussed first.
Following this, information is provided on \glspl{DNP} and \gls{MSR} fuel depletion.
