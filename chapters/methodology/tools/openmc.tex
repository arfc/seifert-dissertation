OpenMC is an open-source Monte Carlo neutron and photon transport code.
Its Python \gls{API} offers functionality that simplifies interfacing with \gls{MoSDeN}, an in-house developed open-source Python package.
The sample irradiation process is straightforward and configurable, as users can adjust parameters through an input file.
OpenMC also offers useful feature in depletion, where a zero-power depletion step is rapidly calculated since only depletion is tracked.
This feature allows resolving ex-core residence time depletion steps quickly.
Additionally, OpenMC’s transfer rate functionality during depletion enables simulation of chemical removal in an \gls{MSR}.

For this work, \gls{MoSDeN} by default uses the \gls{ENDF}/B-VII.1 based depletion chains provided by OpenMC and \gls{ENDF}/B-VII.1 cross section data.
The thermal spectrum chain applies to neutron irradiation below $1 \; eV$, the fast spectrum chain applies to neutron irradiation above thermal and below $5 \; MeV$, and anything above that is not treated in this work \cite{Spriggs2000Summary}.
The models by default assume monoenergetic neutrons irradiate the sample.
