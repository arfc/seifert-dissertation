To evaluate and generate the updated \gls{DNP} group parameters, several external software tools are required.
In-house Python scripts are used to collect and combine various data, OpenMC generates the simplified group parameters, and the \gls{MOOSE} app Moltres is used to both generate higher fidelity and evaluate lower fidelity updated group parameters \cite{python, romano_openmc_2015, lindsay_introduction_2018}.
Further information on each tool is provided in its corresponding sub-section.
