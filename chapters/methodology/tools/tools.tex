Several external software tools evaluate and generate the updated \gls{DNP} group parameters.
In-house Python scripts collect and combine data, OpenMC generates the group parameters, and the \gls{MOOSE} app Moltres evaluates and refines them at different fidelity levels \cite{python, romano_openmc_2015, lindsay_introduction_2018}.
Each tool is described in detail in its corresponding sub-section.
