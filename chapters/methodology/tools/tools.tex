Several external software tools are required to evaluate and generate the updated \gls{DNP} group parameters.
In-house Python scripts collect and combine various data, OpenMC generates the simplified group parameters, and the \gls{MOOSE} app Moltres generates higher fidelity and evaluates lower fidelity group parameters \cite{python, romano_openmc_2015, lindsay_introduction_2018}.
Further information on each tool is provided in its corresponding sub-section.
