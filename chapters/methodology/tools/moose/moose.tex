\subsubsection{Overview}

\gls{MOOSE} is an open-source, parallel, finite element framework for multiphysics applications \cite{giudicelli2024moose}.
\gls{MOOSE} includes many pre-built applications that couple physical phenomena.
The \textsc{Heat Conduction} and \textsc{Navier-Stokes} modules are particularly useful in this work, as they can couple with Moltres for general thermal-hydraulic modeling \cite{permann2020moose, lindsay2023moose, peterson2018overview, park2022verification}.
