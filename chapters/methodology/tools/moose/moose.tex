\subsubsection{Overview}

\gls{MOOSE} is an open-source, parallel finite element framework used to handle multiphysics applications \cite{giudicelli2024moose}
\gls{MOOSE} has many pre-built applications available which coupled physical phenomena.
The \textsc{Heat Conduction} and \textsc{Navier-Stokes} modules are particularly useful in this work, as they are used in Moltres \cite{permann2020moose, lindsay2023moose, peterson2018overview, park2022verification}.
