The Python scripts used in the simplified \gls{DNP} group generation make use of the SciPy, NumPy, Matplotlib, \textit{pandas}, and Uncertainties packages \cite{scipy, numpy, matplotlib, pandas, uncertaintiespackage}.
These scripts set up the OpenMC sample irradiation simulation, collect data from the \gls{IAEA} beta-delayed neutron emission database, combine the OpenMC concentrations with the collected half-life and emission probability data, and fit group parameters to the calculated delayed neutron count curve \cite{DIMITRIOU2021144}.
Section \ref{sec:delnu-groupgen} provides more details on what these scripts do.
