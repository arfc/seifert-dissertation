The validation of the \gls{DNP} group parameters is important to ensure the results will be useful in practice.
Although the group parameters are verified with other group parameters in the literature, this does not necessarily mean they are capturing all of the physical phenomena of interest.
Validation shows where the data may be lacking and conveys potential weaknesses of the approach, depending on the discrepancies between the predicted results and actual results.

Validation of the group parameters generated in this work is conducted in two stages, as discussed in Section \ref{sec:transimpact}.
The first stage validates the delayed neutron count rate formulation and group generation for a static problem.
The second stage validates the updated \gls{DNP} group parameters by comparing the reactivity feedback with that of the static group parameters.

The first stage is validation of the irradiation by comparing the irradiated sample's generated delayed neutron count rate to that of the Keepin et al. experiment from 1957 \cite{keepin1957delayed}.
This requires modeling Godiva in OpenMC and solving the k-eigenvalue problem to irradiate the sample.
The concentration of the sample after irradiation is then passed to the scripts, which will generate the \gls{DNP} group parameters.
The delayed neutron count rate and group parameters are compared with the values from Keepin et al. to determine if there are discrepancies.
Some difference is expected due to uncertainties in the data and the experimental results, so the validation can be considered successful provided the results align within a few percent.
If they do not align, then that would indicate that there is either a bug which was not present during verification or an issue with the data.
If there is an issue with the data, it will be noted for additional future work to improve the microscopic data so that the methodology proposed in this work can be more successfully implemented in the future.

The second stage of the validation is for the generated \gls{DNP} group parameters.
This stage uses the \gls{MSRE} pump start-up and coast-down experimental data to see if the group parameters accurately model the reactivity changes from the \glspl{DNP} \cite{prince1968zero}.
This stage requires modeling the \gls{MSRE} core and upper and lower plena in Moltres.
The effect of the \glspl{DNP} on reactivity is then calculated for both transients using both static and updated \gls{DNP} group parameters.
The expected result is that the updated group parameters will more accurately predict the reactivity from the \glspl{DNP} due to the change in the flow rate.
If neither set of group parameters aligns with the experimental results, then that would indicate an issue with the model, since it has been shown previously that Moltres can model these transients \cite{reynolds2023analysis, park_advancements_2025}.
If the static group parameters more accurately predict the reactivity, then that would indicate that there is an issue with the formation of the updated group parameters, particularly if the first stage of validation was successful.
The issue will have to be resolved before the work can continue, since the updated \gls{DNP} group parameters should provide higher accuracy relative to the static group parameters in \gls{MSR} modeling.
